About This Stream

This application streams video from a ROS 2 node running on a local machine, through AWS Kinesis Video Streams, and to your browser via WebRTC.

Signal Flow

  1. Camera → ROS 2 camera_publisher_node
  2. ros2_nodes/camera_publisher_node → /camera/image_raw (ROS 2 topic)
  3. ros2_nodes/kvs_bridge_node → AWS KVS stream
  4. AWS KVS → Browser (WebRTC)
